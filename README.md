# EXPLAINABLE DEEP LEARNING FOR CROSS-SUBJECT EEG EMOTION RECOGNITION USING GAMEEMO DATASET

This repository contains the implementation and experimental resources for our research on **Explainable Deep Learning for Cross-Subject EEG Emotion Recognition using GAMEEMO Dataset**.

The study investigates whether a deep learning model can learn discriminative emotional representations directly from EEG signals while maintaining generalization across previously unseen subjects. The experiments are conducted using the **GAMEEMO** dataset, which contains EEG recordings collected during gameplay under four emotional states: boring, calm, horror and funny.

### Setup Environment

The experiment is conducted using the following environment and packages:
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- SHAP

### Datset
The dataset is not included in this repository. Download the GAMEEMO dataset from the original source.
